# Storybook audio assets

Sounds of the storybook theatre (children's stories) live in `fixtures/public/audio/storybook/<group>-<n>.ogg`.
Every file is **CC0** and was kept by a person after listening to it. Budget for the folder: **12 MB**.
Groups and trigger words: `packages/scene-spec/src/storybook-sounds.ts`. Variants per group, with the
synth fallback used until a file exists or when it fails to load:
`packages/engine/src/engines/storybook/library.ts` (generated by `pnpm sounds:accept`, do not edit by hand).

## Sources and licences

Only CC0 sources, each read on its own page (checked 2026-11-10; wording stored in `tools/sounds/sources.json`).
Excluded on purpose: Sonniss, Zapsplat, Pixabay, Freesound (no API key here) and any AI generator.

## Processing (`tools/sounds/process.ts`)

ffmpeg decodes to mono 32 kHz; then, in order:

- trim leading and trailing silence below -50 dBFS (10 ms RMS windows);
- effects: peak normalised to -3 dBFS, at most 4 s (longer ones are cut and get a 0.3 s fade-out);
- ambience: a 20 s stretch from the middle, last 1.5 s crossfaded (equal power) into the head, so the loop is 8-20 s and seamless; RMS -22 dBFS, peak never above -3 dBFS;
- encode OGG Vorbis mono 32 kHz `-q:a 2`.

Rejected, and listed with a reason in `candidates/<theme>.json`: clipped (more than 0.1 % of the source samples at full scale), too quiet (RMS below -40 dBFS after normalising), too long (effect source over 120 s, ambience source over 300 s), too short for a loop, silent.

## Workflow

1. `pnpm sounds:fetch --dry` lists files, sources and sizes. Nothing is downloaded.
2. After the user approves the list: `pnpm sounds:fetch --approved` (into `tools/sounds/cache/`, git-ignored).
3. `pnpm sounds:process` writes `tools/sounds/candidates/<theme>/<group>-<n>.ogg` and the sheets (git-ignored). Running it again is safe: the work is swapped in only when everything succeeded and the decisions are kept for candidates that still exist. It replaces the whole theme folder, so the synth candidates of step 3b are gone.
3b. `pnpm sounds:synth` (optional) renders offline synth candidates (`<group>-s<n>.ogg`) for the groups without a real sound, so a person can listen to them too. **Re-run it after every `sounds:process`.**
4. `pnpm sounds:listen` serves http://127.0.0.1:5175 (this machine only): play, Keep or Discard each candidate, "Tema successivo" for the next theme. Decisions go to `candidates/<theme>.decisions.json`.
5. `pnpm sounds:accept` copies the kept files, regenerates the library (a group with kept files is replaced as a whole: `file: true`, synth fallback kept) and rewrites the table below.
